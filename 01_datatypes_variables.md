1. Concept in my own words:
Datatypes and variables are units that C# can use to store information while a program is running. A variable is like an empty box having a name, you can 
add stuff into it (information), and followed by that is the datatype which can tell computer what type of information can go into that box. For instance,
"int" can allow whole numbers, "string" can allow words or sentences. We can declare the variables so that the program can remember values and use them later.
When the program runs, it reads the variables, then does something with them, as I said before, you can add values to one variable if it is empty or you can 
change the value in the variable to another variable. If you do something that leads to an error, it will not execute and tell you what's wrong.

2. Key C# Syntax.
- Structure of a variable is datatype, name and value
- Basic syntax:
int age = 17;(int: datatype, age: variable name, 17: value (in this case, a value must be a int, so only integer is allowed))
string name = "Duong Quang Toa";(string: datatype, name: variable name, Duong Quang Toa: value(in this case, a value must be in quotation mark if the datatype is STRING))

If you have declared the datatype of variable and a value already, in next time, you dont need to declare again if you want to change the value.
For instance:
int x = 5;
x = x + 2;

3. Eureka Exercise/Moment:
At first time I learned about all datatypes, i was confused of float and double. I didn't know when i need to use float and the same as double. Later, I did some research 
and found out that the difference between them is the range, memory usage and other things. For instance, in memory usage, float uses 4 bytes of memory but double uses 8 bytes
memory. After that, It made more sense when I did the assignments.

4. Common beginner mistake:
In my opinion, the most mistake beginners can make is putting the wrong type of value into a variable. It was also my mistake at the beginning of the course.
After realizing about the must you need to follow when matching the datatypes to the variables, it will make sense for you.
