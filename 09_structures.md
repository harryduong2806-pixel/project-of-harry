1. Concept in my own words:
Struct concept is a custom data type that lets you group many things that related to each other (like they have 1 common thing that a thing have, like 
a student have name, grade, address and other things). It's useful when you want to organize data that belongs together instead of keeping them seperate.
They can connect to other concepts, too.

2. Key C# Syntax:
- Basic syntax and example:
struct nameof {
	public string B;
	public int C;
}

A.s;
s.B = "Quang Toa";
s.C = 286;

- fields inside the struct hold the data
- You can access the field by using "."
