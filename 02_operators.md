1. Concept in my own words:
Operators are symbols (can be arithmetic, comnparision or logical) that can tell the computer what to do with the value, like adding numbers, comparing values,
or checking conditions. They help your program make decisions and change data as it runs. For instance, "+" operator add two or more values, "==" operator checks if
two things are equal or not. Operators are important because they can relate directly (can be used) in other concepts like if-statement, loops and array.

2. Key C# syntax:
- As i said before, operators fall into three group: arithmetic, comparision, logical (used in declaring value to variable)
- For instance:
int a = 5 + 3;(=: assignment, +: arithmetic)
bool bigger = 10 > 4; (comparision and turn "bool" into true or false, in this case is TRUE)
bool both = true && false; (logical)

3. Eureka Exercise/Moment:
The exercise that helped me understand operators was when I did an assignment that turns a number of days into year. There was two arithmetic that made me confused
("/" and "%="). After that, i did some research and found out that "/" is division but only take the integer without remainder and "%=" is only taking the remainder
without integer part.

4. Common beginner mistake:
A common mistake beginners can make is "||" and "&&". One is "or" and one is "and", without understanding clearly, they can make some mistakes in assignment using concepts
like "if-statement".
