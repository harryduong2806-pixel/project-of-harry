1. Concept in my own words:
Function is a reusable block of code that performs a specific task. You will put all the code into a function and call it whenever you need to use it.
Function can take parameters and can return a value back to you. This concept can connect to almost everything else.

2. Key C# Syntax:
- Return type
- Name of function
- Parameters

For instance:
int Add(int a, int b) {
    return a + b;
}

int result = Add(3, 4); // result = 7
